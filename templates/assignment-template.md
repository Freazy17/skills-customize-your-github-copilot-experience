## 🧭 Template Guidelines (project standards)

Use these brief guidelines when creating or editing `README.md` assignment files:

- Follow the structure above and do not remove required sections.
- The file must be named `README.md` and placed in the assignment folder.
- Title: short, descriptive (replace `[Assignment Title]`).
- Objective: 1–2 sentences focusing on learning goals.
- Tasks: give action-oriented task names, clear descriptions, and measurable requirements.
- Provide example input/output when helpful and include a small evaluation checklist.
- Use student-friendly language and keep examples short and focused.

## 🔎 Minimal Example

```md
# 📘 Assignment: Loops and Conditionals

## 🎯 Objective

Implement programs that practice `for` and `while` loops and basic conditional logic.

## 📝 Tasks

### 🛠️ Count Vowels

#### Description
Write a function that counts vowels in a given string.

#### Requirements
- Function `count_vowels(s: str) -> int` that returns the number of vowels.
- Include at least three test cases in the `README.md`.

```

## 💡 Tips for authors

- Provide a `starter-code` file when it helps students get started (e.g., `starter-code.py`).
- If using data, include a small sample dataset in the assignment folder.
- Keep external dependencies minimal and document any required packages.
